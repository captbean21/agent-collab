### Output Token Limit Strategy (Auto-captured as skill: `staged-large-output-generation`)

**Problem:** Nemotron 3 Ultra free tier = 4,096 output tokens. Large code writes + explanations exceed ceiling.

**Solution that worked (tested tonight):**
1. **Write files via `exec` + `cat`/`tee` instead of `write` tool** — tool calls count toward output budget; shell redirections don't
2. **One file per turn** — complete one file, report done, yield 60s, continue
3. **No explanatory text in same turn as file writes** — separate "reporting" turns from "execution" turns
4. **Use `exec` with `yieldMs: 60000`** for natural pauses between stages

**Pattern:**
```bash
exec:
  command: "cat > path/file.py << 'EOF'\n...content...\nEOF"
  yieldMs: 60000
  title: "Descriptive stage name"
```

**Result:** Built 6-file harness across 8 stages with **zero output limit hits**. Dry-run validates config successfully.
