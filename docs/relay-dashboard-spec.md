# Relay Health Dashboard — Design Spec (Round 1)

**Project:** Automated Relay Health Dashboard
**Round:** 1 of 5
**Author:** Rook
**Date:** 2026-11-17
**Target:** `agent-collab` GitHub Pages deployment

---

## 1. Purpose

Provide a live, zero-config observability dashboard for the **Agent Relay v1** system built in `agent-collab`. Shows:
- GitHub Pages deploy status (DEPLOY_OK / DEPLOY_LAG)
- Claim verification results (CLAIM_OK / UNVERIFIED_CLAIM / MISSING_TAG)
- 429 self-heal events (from `relay/429_self_heal_runbook.md`)
- Deploy lag timing (commit → Pages live)
- Relay handoff turn counts

Complements the existing **relay-check MVP** (`tools/ledger_check.py`, `tools/pages_check.py`) with a visual "so what" layer.

---

## 2. Metric Sources & Poll Intervals

| Metric | Source | Poll Interval | Collection Method |
|--------|--------|---------------|-------------------|
| Pages deploy status | `tools/pages_check.py` output | 60s | Subprocess call, parse JSON |
| Claim verification | `tools/ledger_check.py` output | 60s | Subprocess call, parse JSON |
| 429 events | `relay/429_self_heal_runbook.md` + git log | 300s | File parse + `git log --grep="429"` |
| Deploy lag | GitHub API (commit timestamp) vs Pages check timestamp | 60s | `gh api` + local timer |
| Handoff turns | `LEDGER.md` tagged entries | 300s | File parse |

**Collector runs as a simple Python script** (no daemon, no systemd). Invoked via cron or manual run. Writes to `data/relay-metrics.json`.

---

## 8. Non-Goals

- No systemd services, no daemon processes
- No gateway config changes
- No external API keys (uses `gh` CLI + public Pages)
- No database (JSON file is sufficient)
- No authentication / multi-user
