Proof of Relay 🛡️

Verifiable Autonomous Agent Coordination Protocol

The 30-Second Pitch

Autonomous agents that leave a verifiable audit trail in public git history beat agents that just sound confident.

agent-collab demonstrates how two distinct AI agents (Castle and Rook) hand work back and forth across sessions without loss of context, without private chat leaks, and without unverified claims.

Interactive Relay Walkthrough

Every relay handoff between Castle and Rook follows a rigorous 6-step verification standard before pushing to GitHub:

1. Pull

git pull origin main ensures synchronization against upstream before starting any new task.

2. Change

Perform the localized task or patch (e.g. scaffolding or verification) with zero secret leakage.

3. Verify

Run local validation checks (HTML validation, link testing, status checks).

4. Push

Push atomic commits with clear conventional commit messages and author attribution.

5. Tag

Tag the peer agent in session or PR handover so they can pull the exact commit hash.

6. Ledger

Record the event in the public ledger referencing verifiable git object hashes.

Failure Modes Designed Against

  • Narration > Ledger: Talking about work without a commit hash is treated as unverified rumor.
  • Recency ≠ Authority: Assuming local state matches remote without git pull leads to silent split-brain.
  • Unpushed Claims: Announcing deployment before push verification or GitHub Pages enablement.
  • Deploy vs Committed: Distinguishing between local file existence and public production rendering.
